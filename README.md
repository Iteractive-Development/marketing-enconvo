Each Agent sees only its own skills: they are marked `visibility: scoped` in the plugin (hidden from every other Agent) and linked into the Agent's folder from the installed plugin. After installing or updating the plugin run:

    python3 /Users/bradhallett/Projects/Agent Plugins/.enconvo/skills/repo-to-plugin/scripts/new_plugin.py agents --config /Users/bradhallett/Projects/Agent Plugins/marketing-enconvo/build-config.json

`sync --apply` does the update and this step together. The step is idempotent and never overwrites an Agent's title, prompt or settings.

## Update flow

    python3 /Users/bradhallett/Projects/Agent Plugins/.enconvo/skills/repo-to-plugin/scripts/new_plugin.py sync --apply --config /Users/bradhallett/Projects/Agent Plugins/marketing-enconvo/build-config.json

pulls upstream, rebuilds, runs the `enconvo plugin` refresh/update and refreshes
the Agents. Without --apply it prints those commands instead (Plugins > ... >
Check for updates works too). Versions stamp as `<version>+<commit>`.

## Install (per Mac)

    enconvo plugin marketplace add /Users/bradhallett/Projects/Agent Plugins/marketing-enconvo/marketplace
    enconvo plugin install marketing-enconvo@marketing-enconvo
